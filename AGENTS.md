# Instrucción editorial

Cuando el usuario pide agregar o actualizar contenido, el pedido incluye publicarlo por el circuito normal documentado en `README.md`; no hace falta pedir otra aprobación para esa publicación. El trabajo se considera completo solo después de verificar que el contenido sea visible en producción en todos los idiomas afectados. Si la publicación o la verificación queda bloqueada, informar el bloqueo sin afirmar que se completó.
